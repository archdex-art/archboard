Then

Find it, see it, open it

Archboard detects what you actually have installed by reading application bundles, not by guessing at command names that may not be on your path.

Your editor

VS Code, Cursor, Zed, the JetBrains IDEs, Xcode, Sublime and more. Pick a default per project, or open with any of them.

Your terminal

Terminal, iTerm2, WezTerm, kitty, Alacritty, Ghostty and Warp — opened in the project directory, with your shell environment intact.

The folder

Revealed in Finder, one keystroke, without hunting through three levels of nesting to find where you put it.

The remote

GitHub, GitLab, Bitbucket, Azure DevOps, Codeberg, SourceHut or self-hosted. The URL is parsed, never assumed.

From anywhere

One click

Open the editor and start the work

Save the commands you always run in a project. Mark the ones that belong to starting work, and a single click opens your editor and runs each of them in its own terminal window.

Open Cursor + bun run dev + bun test --watch

Nothing is ever read from a project’s own files. The commands are the ones you typed, and they run because you clicked, not because a repository suggested them.

The case against

When you don’t need this

If you already know which project you want, Raycast opens it in about a second and zoxide is faster still. Archboard will not beat either of them at that, and the technology labels on each row are decoration to the person who wrote the code.

It earns its place on one question only: which of my repositories have work I did not finish? Nothing else answers that without opening them one at a time. That is the whole product — it is narrow, and it is real.

First launch will be blocked

This build is signed ad-hoc, not notarized by Apple, so macOS refuses it the first time. Open the DMG, drag Archboard to Applications, then run this once: 

xattr -dr com.apple.quarantine /Applications/Archboard.app

The app must not be running when you run it. On macOS 14 and earlier you can right-click the app and choose Open instead; that shortcut was removed in macOS 15.
